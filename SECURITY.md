# Security Policy

## Reporting a Vulnerability

You can report suspected vulnerabilities either privately or publicly:

- **Private disclosure (recommended for sensitive issues):** Use the security
  advisory form in the
  [meta-vulnscout GitHub repository](https://github.com/savoirfairelinux/meta-vulnscout/security/advisories/new).
- **Public disclosure:** It is also fine to open an issue directly on the
  [meta-vulnscout issue tracker](https://github.com/savoirfairelinux/meta-vulnscout/issues).

Include the affected version, reproduction steps, impact, and any suggested
mitigation. The maintainers will acknowledge the report, investigate it, and
coordinate disclosure and remediation with the reporter.

Security fixes are provided for the current development branch. Users should
upgrade to the latest available revision before reporting an issue.
